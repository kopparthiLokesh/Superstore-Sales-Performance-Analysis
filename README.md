# Superstore Sales Performance Analysis | SQL & Power BI

An end-to-end sales analysis of the Superstore dataset. I used **SQL** to clean, query, and analyze the data, and **Power BI** to build an interactive dashboard that shows sales trends, profitability patterns, and key business KPIs.

![Superstore Power BI Dashboard](Dashboard.png)

## Business Questions

- Which product categories drive the most sales, and which are the most profitable?
- Which customer segments contribute the most revenue?
- How does demand change across the year?
- How do sales and profit vary across regions, shipping modes, and order periods?

## Key Findings

- **Technology** generated the highest sales, while **Office Supplies** had the highest profit margin. The top revenue category is not the most profitable one.
- The **Consumer** segment contributed over **50% of total revenue**.
- **Q4** accounted for nearly **38% of annual sales**, which points to strong seasonal demand.

## Approach

1. **Data quality checks:** reviewed the data for missing values, duplicates, and inconsistencies before analysis.
2. **SQL analysis:** analyzed performance across products, categories, regions, customer segments, shipping modes, and order periods.
3. **Dashboard:** built an interactive Power BI dashboard to present the results.

## SQL Techniques Used

- Aggregations with `GROUP BY` and `HAVING`
- Common Table Expressions (CTEs)
- Window functions: `LAG` and `RANK`

## Power BI Dashboard

The dashboard includes:

- KPIs
- Monthly sales trends
- Category performance
- Customer segment analysis
- Shipping mode analysis
- Product-level insights
